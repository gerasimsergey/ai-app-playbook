# AGENTS.md: сделать полезное и прибыльное приложение

> Перевод [AGENTS.md](https://github.com/blakeandersonw/ai-app-playbook/blob/main/AGENTS.md). MIT © Blake Anderson

Ты кодинг-агент (Claude Code, OpenCode, Codex, …). Человек хочет сделать на этом стеке приложение, которое улучшает жизнь людей (форма, концентрация, учёба, сон, питание) и приносит деньги.

Если тебе сказали склонировать этот репозиторий и прочитать этот файл: прочитай его целиком, затем начни **Этап 0** с вопросов Этапа 0.

Веди человека через все этапы по порядку. Шаги **[AGENT]** делай сам. Для шагов **[HUMAN]** давай точные инструкции. Не пропускай **Ворота A**.

---

## Правила

1. **Сначала польза.** Давай то, что обещает приложение. Честные пробные периоды, лёгкая отмена, никаких тёмных паттернов.
2. **Сначала UX.** Выбирай более быстрый и простой вариант.
3. **Используй только этот стек:**

| Задача | Чем |
|---|---|
| Сервер, данные, файлы, фоновые задачи, почта, хостинг | **Cloudflare**: Workers (простой обработчик `fetch`), D1 (чистый SQL), R2, KV, Durable Objects, Queues, Workflows, AI Gateway, Email Service, Turnstile |
| Вход | **Better Auth** (библиотека внутри Worker) |
| База на масштабе | **PlanetScale** через Hyperdrive |
| AI | **OpenRouter**, по умолчанию **DeepSeek**. Модели выбирай через **Artificial Analysis** плюс свои тесты (evals) |
| Свои AI-процессы на больших объёмах | GPU **Vast.ai** / **RunPod** (распознавание речи, генерация картинок, свои LLM). Только модели; управление остаётся на Cloudflare |
| Оплата | **Superwall** (iOS/Android) · **Stripe** (веб) |
| Аналитика + ошибки | **Tinybird** |
| Клиенты | **SwiftUI** для iOS · **React Native** или **Kotlin** для Android · **React + Vite** для веба |
| Код | **Claude Code** (максимум качества) · **OpenCode + DeepSeek** (экономия) |

4. **Не используй:** Vercel, Netlify, Lovable, Bolt, v0, Replit (хостинг), Bubble, FlutterFlow, Firebase, Supabase, Heroku, Render, Railway, AWS Amplify, Clerk, Auth0, Sentry, PostHog, Next.js, Hono, Drizzle, Prisma. Если стек чего-то не умеет, остановись и спроси.
5. Спрашивай, прежде чем добавить зависимость. Предпочитай API платформы (fetch, SQL, CSS-переменные, SwiftUI).
6. Вся серверная логика работает на Cloudflare. Ключи никогда не попадают в клиенты.
7. Сначала staging. Никогда не трогай боевые данные и не запускай боевые деплои или миграции.
8. Прежде чем сказать «готово»: запусти проверки и тесты и посмотри на работающее приложение.
9. Делай быстро (глава 01): основной цикл целиком в первый же день, подделывай то, что ещё не сделано, копируй сценарии с образцов, каждый день выкладывай в TestFlight, остальные идеи записывай в `docs/later.md`.

## Чек-лист

Скопируй в `docs/progress.md` приложения. Обновляй и показывай после каждого этапа.

### Этап 0: найти и проверить нишу (1–7 дней) · ВОРОТА A

- [ ] **[AGENT]** Спроси одним сообщением: кого ты знаешь или к какой группе принадлежишь? Что эти люди вставляют в ChatGPT? На что жалуются? За какие приложения платят?
- [ ] **[AGENT]** Предложи 3 ниши (глава 00): одна фраза, 2–3 приложения-образца, подводные камни области, оценочная таблица (7 критериев, по 1–5).
- [ ] **[AGENT]** Лучший кандидат: прочитай отзывы конкурентов в App Store на 1–3★, напиши 10 зацепок для коротких видео, сделай черновик сайта с листом ожидания (Worker + D1).
- [ ] **[HUMAN]** Неделю публикуй видео и лист ожидания.
- [ ] **[AGENT]** Посчитай юнит-экономику по главе 12 с ценой, которую выбрал человек.
- **Ворота A, строить только если:** оценка ≥ 25/35 и нет единиц · есть сигнал спроса (сохранения, репосты, «что это за приложение?», в лист ожидания записались ≥ 10% посетителей) · выручка на скачивание (глава 12) заметно выше стоимости скачивания.

### Этап 5: AI

- [ ] **[HUMAN]** Создай AI Gateway; задай `OPENROUTER_API_KEY` через `wrangler secret put`.
- [ ] **[AGENT]** `ai.ts`: DeepSeek через AI Gateway, потоковый вывод, таймаут + запасная модель, событие `ai_call` со стоимостью, квоты на сервере (пробный период против подписчика).
- [ ] **[AGENT]** Выбери модели через Artificial Analysis (глава 05): самую дешёвую из лучших для каждой задачи (текст, картинки, видео, речь), затем прогони тесты.
- [ ] **[AGENT]** `evals/`: 20+ настоящих входных данных и скрипт оценки. Модель дороже бери, только если DeepSeek не справился.
- **Готово, когда:** основная функция стримит на staging, события `ai_call` показывают стоимость, а квота блокирует вызовы сверх лимита.
