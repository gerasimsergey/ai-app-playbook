# 09 · Дизайн и UX

> **Приоритет №1.** UX важнее любого другого решения в этой книге.
> **Агенту: читать, когда** делаешь любой экран, сценарий или анимацию. Сначала выбери по таблице ниже приложения-образцы для этого типа продукта, запиши их в `docs/brief.md` и изучи их сценарии.

## Приложения-образцы

Выбери 2–3, подходящие к твоему продукту.

| Продукт | Изучи | Повтори |
|---|---|---|
| **Снимок / скан → результат** | Cal AI, Yuka, PictureThis, Photomath | Камера сразу; результат за ~1 с; крупная оценка; вердикты цветом |
| **Ежедневная привычка / учёба** | Duolingo, Finch, Speak | Серии, персонаж, празднование, звук, короткая сессия, следующий урок уже ждёт |
| **План / коучинг** | Ladder, экран плана Cal AI, Flo | Показ плана, главный экран «сегодня», кольца прогресса, отметки |
| **AI-чат / компаньон** | [EcoGPT](https://ecogpt.com), ChatGPT, Speak | Потоковый текст, мгновенная навигация, подсказки запросов, голос |
| **Фото / творчество** | Remini, Lensa, CapCut | Ползунок «до/после», короткое ожидание с прогрессом, поделиться и сохранить в одно касание |
| **Вера / осознанность** | Hallow, Headspace, Calm | Спокойная палитра, в первую очередь аудио, ежедневный ритуал, мягкие напоминания |
| **Фокус / продуктивность** | Opal, Structured, Things | Наглядная шкала времени, приятное завершение, виджеты |
| **Маркетплейс / работа** | SideShift, Airbnb, Depop | Карточки со свайпом, признаки доверия, откликнуться или купить в одно касание |
| **Деньги** | Cleo, Copilot Money | Характер в текстах, понятные графики, итоги недели |
| **Внешность / стиль** | Umax, сканеры кожи | Сценарий селфи, разбор оценки, план ухода, бережные формулировки |

Экраны: **[Mobbin](https://mobbin.com)**, **[Screens Design](https://screensdesign.com)**. Пейволы: **[галерея Superwall](https://superwall.com/applications)**.

## Как найти интерфейс для повторения (шаги агента)

1. **Составь список лидеров** через Search API Apple (без ключа):
   ```bash
   curl "https://itunes.apple.com/search?term=calorie+tracker&entity=software&country=us&limit=25"
   ```
   Сортируй по `userRatingCount` и `averageUserRating`. В результатах есть `screenshotUrls`, `description`, `trackViewUrl`.
2. **Сохрани скриншоты** в `docs/references/<app>/`.
3. **Возьми полные сценарии** (онбординг, пейвол, главный экран, настройки) с [Mobbin](https://mobbin.com), [Screens Design](https://screensdesign.com) и из [галереи Superwall](https://superwall.com/applications). Человек может также положить записи экрана в `docs/references/`.
4. **Посмотри TikTok и Instagram** по «[название приложения]» и «[категория] app», чтобы понять, какие моменты снимают авторы.
5. **Напиши разбор** каждого образца в `docs/references/<app>.md`: сценарий, раскладка, визуал (шрифты, отступы, скругления, палитра, светлая/тёмная тема), анимации, тексты.
6. **Выбирай один образец на экран**, а не на приложение.
7. **Собери заново в своей дизайн-системе** и сравнивай рядом (превью SwiftUI или браузер шириной с телефон), пока не совпадёт.

Копируй паттерны, а не материалы: никаких логотипов, иллюстраций, иконок, персонажей, защищённых текстов и названий брендов.

## Принципы

1. Быстро: оптимистичный интерфейс, скелетоны, потоковый текст, отклик на касание меньше 100 мс.
2. Одно главное действие на экран.
3. Польза до регистрации ([04](04-auth.md)).
4. Пружинные анимации; тактильный отклик на важных касаниях.
5. Празднуй прогресс: серии, кольца, «у тебя получилось».
6. Родные соглашения каждой платформы.
7. Доступность: Dynamic Type, контраст, подписи VoiceOver, зоны касания 44 pt.
8. Честность: настоящие пробные периоды, лёгкая отмена, никакой искусственной срочности.

## Онбординг (шаблон Cal AI / Duolingo)

1. Зацепка: одно обещание, одна кнопка.
2. 5–15 личных вопросов с полосой прогресса.
3. Социальное доказательство где-то посередине.
4. «Составляем твой план…» с анимированными шагами.
5. Персональный результат (момент «ага»).
6. Аккаунт (Apple в одно касание), если нужен.
7. Пейвол: бесплатный пробный период, выделенная годовая подписка.
8. Первый успех в течение 60 секунд.

Отслеживай каждый шаг ([08](08-analytics-observability.md)).

## Дизайн-система

- Токены: цвет (светлая и тёмная тема), шкала шрифтов, отступы по сетке 4/8 pt, скругления, тени, длительность анимаций.
- Набор: Button, Card, Sheet, ListRow, Input, Paywall, EmptyState, Toast.
- Одни и те же токены в SwiftUI, Compose и CSS-переменных.
- Иконка и первые 3 скриншота дают основную конверсию в магазине.
