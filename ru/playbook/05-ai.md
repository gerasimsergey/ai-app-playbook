# 05 · AI: DeepSeek через OpenRouter, GPU на объёме

> **По умолчанию:** **DeepSeek** через **OpenRouter**, за Cloudflare **AI Gateway**. Модели выбирай через **Artificial Analysis** и свои тесты. На большом объёме запускай свои процессы на GPU **Vast.ai / RunPod**.
> **Агенту: читать, когда** добавляешь или меняешь любой вызов модели или промпт.

## Схема

```
client ──▶ Worker (auth · quota · rate limit) ──▶ AI Gateway ──▶ OpenRouter ──▶ DeepSeek (or another model)
                         │
                         └── ai_call event (model, tokens, latency, cost) ──▶ Tinybird
```

(Клиент → Worker проверяет вход, квоту и лимит → AI Gateway → OpenRouter → модель. Параллельно Worker шлёт событие `ai_call` с моделью, токенами, задержкой и ценой в Tinybird.)

- **[OpenRouter](https://openrouter.ai):** один ключ, один API, совместимый с OpenAI, запасные провайдеры.
- **[AI Gateway](https://developers.cloudflare.com/ai-gateway/usage/providers/openrouter/):** кэш, логи, лимиты, аналитика трат.
- Никогда не вызывай модели из клиента. Ключи остаются в Worker.

## Модели

`deepseek/deepseek-v4.1-flash-1017` на OpenRouter: около **$0.15 / $0.60 за миллион токенов на вход / выход** (октябрь 2026). Вызов на 1 500 токенов на вход и 400 на выход стоит около **$0.0005**. Два вызова в день — это около **$0.03 в месяц** на подписчика при выручке $2.50 в месяц с подписки $30 в год.

| Задача | Модель |
|---|---|
| Классификация, извлечение, пересказ, чат, планы | **DeepSeek** (по умолчанию) |
| Фото (еда, растение, домашка, кожа) | Самая дешёвая модель со зрением, прошедшая тесты на твоих настоящих фото |
| Ответ, по которому тебя судят, если DeepSeek не прошёл тесты | Передовая модель, только на этом маршруте |

Повышай уровень модели, только когда это оправдывают тесты. Держи id моделей в **KV или переменных окружения**, чтобы переключаться без деплоя.

## Выбор модели: Artificial Analysis

[Artificial Analysis](https://artificialanalysis.ai) сравнивает модели по качеству, скорости и цене.

| Нужно | Рейтинг |
|---|---|
| Текст → текст | [Рейтинг LLM](https://artificialanalysis.ai/leaderboards/models) · [провайдеры](https://artificialanalysis.ai/leaderboards/providers) |
| Текст → картинка | [Text-to-image](https://artificialanalysis.ai/text-to-image) · [арена](https://artificialanalysis.ai/text-to-image/arena) |
| Текст / картинка → видео | [Text-to-video](https://artificialanalysis.ai/video/leaderboard/text-to-video) · [image-to-video](https://artificialanalysis.ai/video/leaderboard/image-to-video) |
| Речь → текст (ASR) | [Speech-to-text](https://artificialanalysis.ai/speech-to-text) |
| Текст → речь (TTS) | [Text-to-speech](https://artificialanalysis.ai/text-to-speech) |

1. Отбери 2–3 самые дешёвые модели из верхушки рейтинга для своей задачи.
2. Проверь скорость (токенов в секунду и время до первого токена; секунды на картинку или ролик).
3. Прогони на отобранных свои тесты. Решают они.
4. Отметь, у каких **открытые веса** (позже можно поднять у себя).

## Правила

1. Всё отдавай потоком.
2. У каждого вызова таймаут и запасная модель (в OpenRouter `models: [primary, fallback]`).
3. Логируй каждый вызов (`ai_call`): пользователь, функция, модель, токены на вход/выход, задержка, цена, успех.
4. Ограничивай траты на пользователя на сервере: дневная квота для пробного периода, разумный потолок для подписчиков, в D1 или Durable Object.
5. Кэширование промпта: сначала стабильный системный промпт, в конце — то, что ввёл пользователь.
6. Промпты лежат в `prompts/*.md` в git.
7. Ответу модели не доверяй. Проверяй JSON; очищай всё, что выводишь на экран.
8. Текст, который читает модель, — это данные (prompt injection). Инструменты, которые что-то делают, требуют подтверждения.

## Тесты (evals)

- 20–100 настоящих входных данных с описанием, что считается «хорошо».
- Оценивай качество, задержку и цену каждого кандидата. Запускай вручную, не в CI.
- Переключайся, только когда так говорят цифры.

## GPU: Vast.ai / RunPod

Когда API не справляется с задачей или объём большой.

| Процесс | Из чего собрать |
|---|---|
| **Речь → текст (ASR)** | [faster-whisper](https://github.com/SYSTRAN/faster-whisper) и другие открытые модели ASR |
| **Генерация / правка картинок** | Открытые модели через [ComfyUI](https://github.com/comfyanonymous/ComfyUI) или небольшой сервер на Python |
| **Своя LLM** | Модели с открытыми весами (DeepSeek и другие) на [vLLM](https://docs.vllm.ai) или [SGLang](https://docs.sglang.ai) |
| **Видео, голос, TTS, апскейл** | Открытые модели из рейтингов Artificial Analysis |

- **[Vast.ai](https://vast.ai):** маркетплейс GPU, обычно самый дешёвый за час GPU; для стабильной большой нагрузки. ([цены](https://vast.ai/pricing) · [документация](https://docs.vast.ai))
- **[RunPod](https://www.runpod.io):** постоянные поды и **[serverless](https://docs.runpod.io/serverless/overview)**, который сжимается до нуля; для нагрузки скачками. ([цены](https://www.runpod.io/pricing))

Арендованный GPU стоит одинаково в час и при 10, и при 10 000 запросов. Когда процесс загружает GPU большую часть дня, свой хостинг часто в несколько раз дешевле API, иногда в 10 раз. При меньшей загрузке дешевле API.

1. Начинай с API. Переноси процесс на GPU, когда его счёт большой и стабильный или API не умеет это делать.
2. GPU-машины только запускают модели. Маршрутизация, очереди, повторы, вход, квоты, оплата остаются на Cloudflare; Worker вызывает адрес GPU.
3. Держи автоматический запасной путь на OpenRouter или облачный API.
4. Считай цену за результат (картинка, минута аудио, 1 тыс. токенов) для обоих путей в Tinybird.
5. Упаковывай каждый процесс в образ контейнера с зафиксированными весами.
6. Масштабируй автоматически по длине очереди.
